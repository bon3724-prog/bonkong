인스타그램 "오늘 놓치면 손해 보는 정보" 카드에 넣을 정보를 골라 JSON 파일로 저장해줘.
대상 독자는 한국의 일반 소비자(20~50대)다. 이 카드는 게시 전에 사람이 확인하지만, 마감일·금액이 틀리면 독자가 실제로 손해를 보므로 확인되지 않은 정보는 절대 넣지 않는다.

[입력]
- 최근 뉴스 묶음(digest): 아래 "읽을 파일" 목록. 각 줄의 대표 제목·요약·링크를 후보로 본다.
- 최근 7일 동안 이미 올린 정보: 아래 "최근 게시 목록". 같은 정보는 다시 넣지 않는다(마감 하루 전 재알림만 예외로 1개까지).
- 필요하면 WebSearch로 이번 주 신청 마감인 정부·지자체 지원금(정부24·보조금24·복지로·각 지자체 공지)을 추가로 찾는다.

[고르는 기준]
1. 카테고리는 셋 중 하나: "지원금"(정부·지자체·공공기관 지원금·바우처·환급), "신청 마감"(신청·접수 기한이 곧 끝나는 것 — 지원금이 아닌 무료 검진·교육·등록·추첨 등), "할인"(대형 유통·통신·카드·앱의 기간 한정 할인·쿠폰·무료 증정).
2. 게시일({DATE}) 기준으로 아직 신청·이용할 수 있어야 한다. 마감일이 게시일 이전이면 제외. 마감이 게시일로부터 0~7일 안인 것을 우선한다. 마감일이 정해지지 않은 상시 혜택은 넣지 않는다.
3. 전국 누구나 또는 넓은 대상(예: 만 65세 이상, 서울시민, 청년)이 이용할 수 있는 것을 우선. 아주 좁은 대상(특정 업종 사업자, 한 동네 주민 등)은 제외.
4. 3~5개를 고르고, 가능하면 카테고리를 섞는다. 확인된 게 3개가 안 되면 확인된 것만(1~2개) 넣는다. 하나도 없으면 items를 빈 배열로 둔다.
5. 제외: 대출·투자·코인·보험 가입 권유, 도박·성인·담배·술, 의약품, 특정 정치 주장, 경품 이벤트처럼 당첨 확률이 낮은 것, 기업 홍보성이 강하고 소비자 이득이 작은 것.

[반드시 할 사실 확인]
- 각 항목마다 WebFetch로 공식 출처(정부·지자체·공공기관 공지, 또는 해당 기업 공식 공지/보도자료) 페이지를 직접 열어 대상·혜택·마감일·신청 방법을 확인한다. 기사만 보고 쓰지 않는다.
- 공식 페이지를 열 수 없거나 내용이 기사와 다르면 그 항목은 넣지 않는다.
- 금액·날짜·시간은 공식 페이지 표기 그대로. 추측·반올림 금지.

[출력 — 이 경로에 UTF-8 JSON으로 Write]
{OUT_PATH}

형식(키 이름 그대로):
{
  "date": "{DATE}",
  "created_at": "YYYY-MM-DDTHH:MM+09:00",
  "status": "draft",
  "headline": "커버에 들어갈 한 줄 (16자 이내, 예: 이번 주 마감 지원금 3가지)",
  "items": [
    {
      "category": "지원금 | 신청 마감 | 할인",
      "title": "카드 제목 (20자 이내, 무엇인지 바로 알게)",
      "who": "대상 (30자 이내)",
      "benefit": "혜택 (35자 이내, 금액·할인율 포함)",
      "deadline": "YYYY-MM-DD",
      "deadline_note": "시간·조건 등 짧은 보충 (예: 18시까지, 예산 소진 시 조기 마감) — 없으면 빈 문자열",
      "how": "신청·이용 방법 (35자 이내)",
      "source_name": "출처 이름 (예: 보건복지부, 서울시, 이마트 공식 공지)",
      "source_url": "확인한 공식 페이지 주소",
      "checked": "{TODAY} 공식 페이지 확인"
    }
  ]
}

[문구 규칙]
- 존댓말 대신 짧은 명사형·해요체 혼용 가능하나 과장 금지("무조건", "역대급", "100% 받는" 금지).
- 겁주는 표현 금지. "놓치면 손해"는 제목에서만 쓰고 항목 문구에는 쓰지 않는다.
- 글자 수 제한을 지킨다(카드에 들어가야 함).

JSON 파일 저장이 끝나면, 고른 항목마다 한 줄씩 "카테고리 | 제목 | 마감 | 출처 URL"을 출력하고, 후보였지만 뺀 것과 그 이유를 짧게 출력해.
